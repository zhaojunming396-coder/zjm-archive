# Changelog

## v0.5.4

- 新增 Sites 发布配置，准备把训练助手部署成手机可访问的网址。
- 新增标准发布外壳，网站根地址会自动进入训练助手。
- 将当前训练助手静态资源同步到发布目录，保证部署版本和本地版本一致。

## v0.5.3

- 新增 PWA 配置，支持手机浏览器添加到主屏幕。
- 新增离线缓存，基础页面和核心脚本会被缓存到手机本地。
- 新增应用图标，用于手机主屏幕显示。
- 新增根入口页，部署后打开网站根地址即可进入训练助手。

## v0.5.2

- 完善首页“关键动作建议”，每个动作现在显示计划目标、上次表现、本次建议和推荐原因。
- 新增“下次更新”提示：明确告诉用户下一次该加重量、维持、降重量，还是先建立基准。
- 为加重量、维持、降重量、建立基准加入不同视觉状态，方便训练前快速判断。
- 保持首页轻量，不提前加入复杂图表，先把训练决策说清楚。

## v0.5.1

- 首页从普通“今日训练入口”升级为“数据驱动训练反馈”入口。
- 新增今日反馈卡片：根据训练历史判断建立基准、稳定复现、稳定推进、可推进、保守调整或恢复日。
- 新增本周训练反馈：显示本周完成次数、完成度、累计组数和累计训练容量。
- 新增关键动作建议：展示前三个核心动作的上次表现、本次建议重量/目标和推荐策略。
- 修正训练日反馈逻辑：只比较同一训练日的历史容量，避免把上肢、下肢、有氧训练直接混在一起比较。
- 休息日也显示恢复/本周缺口建议，让系统在非训练日仍能提供决策反馈。

## v0.4

- 新增训练数据分析页。
- 新增训练概览：本周训练次数、本月训练次数、总训练次数、总完成组数、总训练容量、最近一次训练日期。
- 新增动作进步分析：最近重量、最近次数、历史最高重量、历史最高训练容量、最近 5 次记录和进步状态。
- 新增 PR 记录：最高重量、最高次数、最高单次容量、最佳训练容量和创造日期。
- 新增简单数据条：最近 7 次训练总容量、最近 4 周训练次数、单个动作最近表现。
- 训练完成总结新增进步提示：本次总容量、同训练日对比和每个动作进步提示。
- 空历史数据时显示中文空状态，不报错。

## v0.3.2

- 导入 JSON 前自动备份当前本地训练数据。
- 新增导入前兜底缓存 `backupBeforeImport.v1`。
- 导入成功提示改为“导入成功，已在导入前备份当前数据。”
- 导入文件格式错误时不会覆盖当前数据。
- 新增配重档位自定义。
- 新增 `equipmentWeightRules.v1`，保存哑铃、杠铃、绳索器械和固定器械档位。
- 建议重量系统优先使用用户自定义档位，没有设置时使用默认规则。
- 封版确认：导入合并、浏览器自动下载拦截、全局器械档位、微信小程序原生文件选择/保存留到后续版本规划。

## v0.3.1

- 新增数据备份页。
- 支持导出本地训练数据为 JSON 文件。
- 支持导入 JSON 备份并覆盖当前本地训练数据。
- 导入前增加中文覆盖确认。
- 导入 JSON 格式错误时显示中文错误提示。
- 新增器械配重档位配置 `equipmentWeightRules`。
- 哑铃按 2.5kg 档位取整。
- 杠铃按 2.5kg 档位取整。
- 绳索器械和固定器械按 5kg 档位取整。
- time_based 动作继续只推荐时长，不推荐重量。
- 优化 `baselineLifts`，补充 `sourceType` 和 `confidence` 字段。

## v0.3

- 新增建议重量系统。
- 新增 `userTrainingProfile.v1` 用户训练档案。
- 支持身高、体重、训练年限、力量水平和基准力量。
- 根据历史记录优先生成本次建议重量。
- 无历史记录时使用基准力量作为保守建议。
- 计时动作显示建议时长，不显示建议重量。
- 训练记录页新增“本次建议”卡片。
- 新增“我的训练档案”页面。
- 写入用户初始训练档案和保守基准力量。
