# 德州扑克胜率与行动记录工具

本项目是一个本地运行的德州扑克学习、复盘和训练工具。它用于记录牌桌信息、估算当前手牌胜率，并把每一圈下注、跟注、加注、弃牌的顺序沉淀成可复盘的行动记录。

> 注意：本工具只适合个人学习和复盘，不应该在真实牌局中实时使用。

## 当前功能

- 选择玩家人数、庄位、小盲和大盲。
- 设置自己的两张手牌和最多五张公共牌。
- 给不同对手座位配置手牌范围。
- 使用快速、标准、精细三档模拟次数估算胜率。
- 根据底池、跟注金额和所需胜率给出简单提示。
- 标记对手弃牌，并自动跳过已弃牌对手。
- 给对手设置标准、紧、松三种手牌风格标签。
- 自动计算当前底池和本圈下注。
- 行动记录面板 v1：
  - 记录下注、跟注、加注到具体数值。
  - 记录弃牌和恢复行动。
  - 记录每一圈结束时收进底池的金额。
  - 显示本手行动顺序和当前圈数。

## 运行方式

这是一个纯前端项目，不需要安装依赖。

直接打开：

```bash
open index.html
```

或者启动本地静态服务器：

```bash
python3 -m http.server 8765
```

然后访问：

```text
http://127.0.0.1:8765
```

## 使用说明

1. 选择玩家人数、庄位和盲注。
2. 选择自己的两张手牌。
3. 根据当前牌局选择公共牌。
4. 选择一个对手座位，填写或套用对手可能手牌范围。
5. 输入每个玩家当前下注额。
6. 点击“分析”查看胜率和底池提示。
7. 每次有人改下注或弃牌后，查看右侧“行动记录”面板。
8. 一圈下注结束后点击“一圈结束”，本圈金额会收进底池并进入下一圈。

## 当前限制

- 胜率计算基于蒙特卡洛模拟，不是精确穷举。
- 当前只分析“我”对一个选中对手的胜率。
- 行动记录面板 v1 主要记录顺序和金额，还没有做完整街道、位置策略或 GTO 路线分析。
- 手牌范围解析只支持常见写法，例如 `22+`、`A2s+`、`KQo`。
- 数据只保存在当前页面状态中，刷新页面后不会持久保存。
