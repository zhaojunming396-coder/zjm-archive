# 手势 ASMR 实验室

一个通过手势触发 ASMR 声音的互动网页作品。用户在摄像头前做出捏合、摩擦、张开、挥手、握拳等动作，系统会把动作转译为不同材质的细微声音和视觉波纹。

## 运行方式

在这个文件夹启动本地服务器：

```bash
python3 -m http.server 8787
```

然后打开：

```text
http://127.0.0.1:8787/
```

点击 `开始` 后允许浏览器使用摄像头。第一次加载手势识别模型需要联网；如果摄像头或模型不可用，作品会自动切换到鼠标演奏模式。

## 交互

- `捏合`：拇指和食指捏合，触发轻敲、折纸、水滴或柔软按压。
- `指向`：只伸出食指，触发单点细节声。
- `双指`：伸出食指和中指，触发两次很近的细节声。
- `摩擦`：手指靠近并轻微移动，触发连续摩擦声。
- `张开`：张开手掌，打开环境噪声和空间感。
- `靠近`：张开手掌并靠近摄像头，触发近耳氛围声。
- `挥动`：快速挥手，触发扫过声。
- `握拳`：让声音收住并变暗。

可切换材质：

- `纸张`
- `水滴`
- `玻璃`
- `织物`

手的位置会影响声音的声像和滤波：左右控制声像，上下控制明暗，移动速度控制声音强度。

## 导入音频素材

项目已经内置一组真实录音素材，点击 `开始` 后会自动加载。当前素材覆盖纸张、水滴、玻璃和织物，并对应捏合、指向、双指、摩擦、张开、靠近、挥动等手势。

点击页面里的 `导入素材`，可以一次选择多个本地音频文件，支持浏览器能播放的常见格式，比如 `.mp3`、`.wav`、`.m4a`、`.ogg`。

推荐用文件名自动分配素材：

```text
纸张_捏合_01.wav
纸张_摩擦_01.wav
水滴_捏合_01.mp3
玻璃_轻敲_01.wav
织物_摩擦_01.wav
玻璃_指向_01.wav
水滴_双指_01.mp3
纸张_靠近_01.wav
fabric_swipe_01.mp3
paper_rub_02.wav
```

文件名里可以包含材质关键词：

```text
纸张 / 水滴 / 玻璃 / 织物
paper / water / glass / fabric
```

也可以包含手势关键词：

```text
捏合 / 摩擦 / 张开 / 挥动 / 握拳
指向 / 双指 / 靠近
pinch / point / two / near / rub / open / swipe / fist
tap / scratch / ambient / brush
```

导入后，真实录音素材会优先触发；没有素材的手势才会使用轻量合成音兜底。

## 作品阐述

这个作品尝试把手的动作转译为听觉中的触感。用户不需要触摸真实物体，只需要在空气中做出很轻的动作，就可以激活纸、水、玻璃和布料的细微声音。它不是一个普通播放器，而是一个可以用身体演奏的 ASMR 声音装置。
