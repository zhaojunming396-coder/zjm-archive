# Poker and Countdown Tools

这个仓库放了两个个人工具：

## 德州扑克胜率工具

目录：`texas-holdem-tool`

一个本地运行的德州扑克胜率和建议工具，用于个人学习、复盘和训练。打开 `index.html` 就可以使用。

注意：这个工具只适合复盘和学习，不应该在真实牌局中实时使用。

## 日期倒计时工具

目录：`date-countdown-tool`

一个 macOS 日期倒计时小工具，包含 Swift 原生版本、桌面 Widget 版本和 Python Tkinter 版本。

主要目录：

- `DateCountdownNative`：Swift 原生日期倒计时。
- `CountdownWidget`：Swift 桌面倒计时 Widget。
- `DesktopCountdownApp`：Python 桌面倒计时版本。

编译产物没有放进仓库，需要时运行各目录里的 `build.sh` 重新生成。
